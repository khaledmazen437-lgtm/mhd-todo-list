# MHD To-Do

> تطبيق مهام يومي بسيط وأنيق — أضف، علّم كمكتمل، واحذف، كل ده في صفحة واحدة.

A single-page to-do app in vanilla HTML/CSS/JS. Tasks can be added, toggled complete with a click, and deleted with a fade-out animation.

## Features

- Add tasks with the button or the Enter key
- Click a task to mark it complete (strikethrough)
- Delete button with a smooth fade-out
- Cyber-styled glass UI over a generated background image

## Tech Stack

- Vanilla HTML/CSS/JS — no frameworks, no build step

## Running

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

- Tasks are not persisted yet; adding `localStorage` saving is the natural next step.
